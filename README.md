# Backup and Recovery Reference

A backup is a copy of your data you can restore from when the original is lost, corrupted, or compromised. Recovery is the process of getting back to working order from that copy. The common and painful mistake is having backups that have never been tested, then discovering at the worst moment that they do not restore. A backup you have never restored is a hope, not a backup. This reference covers the rules that make backups real: multiple copies in multiple places, tested restores, and clear recovery targets.
